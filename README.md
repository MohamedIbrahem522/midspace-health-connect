# Midspace

A professional healthcare networking platform connecting doctors, hospitals, and patients.

## Features

- Doctor profiles and professional networking
- Job listings and applications
- Patient dashboard and appointment tracking
- Real-time messaging
- Dark/light mode support

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
